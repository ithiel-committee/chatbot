# 展示運用・安全配布マニュアル (iThiel Chatbot)

本ドキュメントは、展示会・学園祭・イベント等の短期運用 (準備1日 + 展示2日 など) において、**レンタルPCや他人のノートPCで安全かつ手軽にアプリを動かすための配布・運用手順書** です。

---

## 1. 基本方針 (結論)

- **配布手段**: Google ドライブではなく **「USBメモリ」** を使用する
- **APIキー管理**: 普段のキーではなく **「展示専用の使い捨てキー」** を新規発行し、**展示終了後に即時削除** する
- **キーの渡し方**: exe の中に埋め込まず、**exe と同じフォルダに `.env` を置いて USB で持ち込む**

---

## 2. 配布・ファイル構成

### なぜドライブ共有ではなく USBメモリなのか？

1. **流出リスクの遮断**: ドライブの共有設定ミスや、クラウド上に課金キー入りファイルが残り続ける事故を防ぐ。
2. **設営スピード・確実性**: 会場や準備室の Wi-Fi 環境が不安定・低速でも、数百MB の exe を瞬時に PC へ展開できる。
3. **撤収の手軽さ**: 終了後は PC 上のフォルダを完全削除 (Shift + Delete) するだけでクリーンアップ完了。

### USBメモリ内のフォルダ構成

USBメモリ内に下記のようなフォルダを作成して持ち込みます。

```text
USBメモリ/
  └── iThiel-Chatbot/
        ├── iThiel-Chatbot-Portable.exe   # ポータブル実行ファイル本体
        └── .env                          # 展示専用のAPIキー等を記述した設定ファイル
```

> **Note**: アプリ (`electron.mjs`) は、exe と同じフォルダに `.env` が存在する場合、それを最優先で自動ロードする仕様になっています。そのため、相手のPCで設定画面を開いてキーを入力する手間はありません。

#### 同梱する `.env` の記述例

```env
# 展示専用に発行した Gemini API キー
GEMINI_API_KEY="AIzaSy..."

# 音声認識方式 (Electronデスクトップ推奨の gemini)
NEXT_PUBLIC_SPEECH_RECOGNITION_MODE="gemini"

# （必要に応じて他の設定項目）
```

## 3. 課金 API キーを守る「3重の安全策」

レンタルPCや他人のPCに課金キーを渡すことになるため、以下の3ステップで金銭被害を完全に防ぎます。

### ① 展示専用キー (使い捨てキー) の発行

普段の開発・個人利用キーは絶対に使わず、Google AI Studio (または Google Cloud Console) で展示専用のキーを1つ新規発行します。

- **キーの名前例**: `iThiel-Exhibition-2026`
- **制限設定**: APIの制限で「Generative Language API (Gemini)」のみを許可

### ② 予算アラート・クォータ (利用上限) の設定

Google Cloud Console 側で以下の安全装置をかけておきます。

- **予算アラート**: 例えば「1,000円」「2,000円」に達した際にメール通知
- **1日のリクエスト上限**: 万が一の連続入力や暴走を防ぐため、1日あたりの最大リクエスト数を設定

### ③ 【最重要】展示終了後の即時キー削除 (Revoke)

展示が終わった瞬間に、手元のスマホや自分のPCから Google AI Studio にアクセスし、**該当の展示用キーを「Delete (削除)」** します。

- **効果**: キーを削除した瞬間にそのキーは無効化されます。相手のPCや USBメモリに `.env` のコピーが残っていても、第三者が利用することは永久に不可能になります。

## 4. イベント運行タイムライン

| フェーズ         | タイミング     | 作業内容                                                                                                                                                                                                 |
| :--------------- | :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **事前準備**     | 展示2〜3日前   | 1. `pnpm run build:exe:portable` で最新の Portable.exe を生成<br>2. Google AI Studio で展示専用の `GEMINI_API_KEY` を新規発行<br>3. USBメモリに `iThiel-Chatbot/` フォルダを作成し、exe と `.env` を配置 |
| **設営・準備日** | 準備日 (1日目) | 1. 現地PCのデスクトップ等に USB から `iThiel-Chatbot/` を丸ごとコピー<br>2. exe を起動し、マイクボタンを押して音声認識・会話ができるかテスト<br>3. ディスプレイ解像度や音量バランスを調整                |
| **展示本番**     | 本番 (2日間)   | そのままブースで運用 (必要に応じてキオスクモードやフルスクリーン表示)                                                                                                                                    |
| **撤収・完了**   | 展示終了直後   | 1. 現地PC上の `iThiel-Chatbot/` フォルダを完全に削除 (Shift + Delete)<br>2. **自分のスマホやPCから Google AI Studio を開き、展示用キーを削除**                                                           |

## 5. トラブルシューティング

- **マイクを押しても反応しない / すぐ切れる**:
  - Windows の「設定」→「プライバシーとセキュリティ」→「マイク」で、アプリへのマイクアクセスが許可されているか確認する。
  - アプリの設定画面（歯車アイコン）→「音声入力」で、音声認識モードが「Google Gemini」になっているか確認する。
- **音声が出ない**:
  - Windows の既定のオーディオ出力デバイス（スピーカー / モニター）が正しく選択されているか確認する。
  - 音声合成（VOICEVOX / AivisSpeech 等）を使用する場合は、該当の音声エンジンがバックグラウンドで起動しているか確認する（クラウド音声の場合は不要）。
